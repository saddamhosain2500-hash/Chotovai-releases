# ছোটভাই — রিলিজ

ছোটভাই AI এজেন্টের তৈরি ফাইল (Android অ্যাপ ও বটের আপডেট)।
অ্যাপের 🔄 আপডেট বাটন আর বটের `/update` কমান্ড এখান থেকেই নতুন ভার্সন নেয়।

- **Chotovai-vN.apk** — কন্ট্রোল প্যানেল অ্যাপ
- **chotovai-agent.zip** — Termux-এ চলা বট (তোমার `.env` আর `data/` এতে নেই, তাই আপডেটে মুছে যায় না)
